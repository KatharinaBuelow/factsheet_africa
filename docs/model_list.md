# Climate Simulations

The climate simulations for Africa are based on
[CORDEX-CORE_AFR22](https://cordex.org/experiment-guidelines/cordex-cmip5/cordex-core/cordex-core-simulations/)
data. More information about CORDEX-CORE is described in the following
papers[^1],[^2],[^3],[^4]).

The data is available on 0.22 deg horizontal resolution and can be
downloaded from the Earth System Grid Federation
([esgf](https://esgf-data.dkrz.de/search/cordex-dkrz)). Model details
and detials to the data format can be found
[here](https://confluence.ecmwf.int/display/CKB/CORDEX%3A+Regional+climate+projections).
More gerneal information on climate models and [model
diagnostic](https://confluence.ecmwf.int/display/CKB/Evaluation+of+CDS+climate+projections)
are documented [Diez-Sierra et al.,
2022](https://journals.ametsoc.org/view/journals/bams/103/12/BAMS-D-22-0111.1.xml).
