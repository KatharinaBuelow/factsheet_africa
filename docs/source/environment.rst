.. _`environments`:


Environments
------------
Before you start, you need to create your environment by

.. code-block:: console

   $ conda env create -f environment-name.yml


The environment to create the fact sheet document:

.. code-block:: bash

   factsheet
   

The environment to create the plots in the factsheet:

.. code-block:: bash

   plotting_fs


The environment to regridd the population data:

.. code-block:: bash

   afrheat

The environment to plot the shape files :

.. code-block:: bash

   cfworld
