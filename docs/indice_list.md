# Climate indicators

The climate parameters used are calculated with the GERICS
[index_calculator](https://github.com/climate-service-center/index_calculator)
berechnet. *Index Calculator* uses
[xclim](https://github.com/Ouranosinc/xclim).

| Climate Index             | Definition                                                                              |
|---------------------------|-----------------------------------------------------------------------------------------|
| Temperature               | The temperature refers to near-surface air temperature (2 m above ground).              |
| Maximum Temperature       | The temperature refers to near-surface air temperature (2 m above ground).              |
| Minimum Temperature       | The temperature refers to near-surface air temperature (2 m above ground).              |
| Hot Days                  | Number of days per year with a daily maximum temperature > 30 °C.                       |
| Very Hot Days             | Number of days per year with a daily maximum temperature > 35 °C.                       |
| Extremely Hot Days        | Number of days per year with a daily maximum temperature > 40 °C.                       |
| Tropical Nights           | Number of days per year with a daily minimum temperature > 20 °C.                       |   
| Precipitation             | Precipitation values are given as average yearly sums in mm per year.                   |
|                           | Values include both liquid and solid precipitation (rain and snow).                     |
| Precipitation ≥ 20 mm/day | Number of days per year with precipitation (rain and snow) reaching or exceeding 20 mm. |
| Dry Days                  | Number of days per year with precipitation (rain and snow) < 1 mm.                      |
| Wet Days                  | Number of days per year with precipitation (rain and snow) ≥ 1 mm.                      |
| Wind Speed                | Mean annual wind speed in m/s.                                                          |
