# Introduction
This repository contains all information and resources required to reproduce a set of climate fact sheets for African countries and sectors. A climate fact sheet is a concise summary of key climate variables, historical climate conditions, projected climate change, and sector-specific climate impacts for a particular country.

Three example fact sheets are included in this repository:

- **Burkina Faso – Agriculture**

- **Togo – Water**

- **Côte d’Ivoire – Health**

Each fact sheet consists of **12 pages** and follows a standardized structure:

**Climate Overview**
An introduction to the country's current climate and observed climate during the recent historical period.

**Climate Change Summary Table**

A table presenting projected climate change for two future time slices under two emissions scenarios. The table also provides information on the robustness and confidence of the projected climate change signals.

**Climate Indicator**

Three pages showing the temporal evolution of selected climate indicators, illustrating future developments.

**Compound Events**

An assessment of projected changes in climate-related compound events.

A key component of this repository is the **`reportlab`** directory, which contains the source code and templates used to generate the individual fact sheet pages.

This repository is intended to support transparency, reproducibility, and the adaptation of the fact sheet methodology to additional countries and sectors across Africa.
